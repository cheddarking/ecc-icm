# Format: brief.md (content)

```markdown
# Content brief: <slug>

Piece: <article|guide|newsletter|thread|post|script|campaign>
Primary platform: <platform>
Also for: <platforms, or none>
Audience: <from config, or overridden>

## The point
<one sentence the reader should be able to repeat>

## Angle
<why this piece and not the obvious version of it>

## Must include
- <facts, examples, links the user supplied>

## Must not
- <topics, claims, tones to avoid>

## Open questions for the user
- <or "none">
```
