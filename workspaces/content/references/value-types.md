# Value Types

ICM Pattern 13: before drafting, agree which kinds of value the piece delivers. A piece that hits none is interesting but does nothing.

| Type | The reader can... | Test |
|---|---|---|
| NOVEL | learn something they could not have found elsewhere | name the source or experience it comes from |
| USABLE | do something differently tomorrow | the piece contains a step, command, or checklist |
| QUESTION-GENERATING | leave with a better question than they arrived with | the question is stated |
| INTERESTING | enjoy it and pass it on | a specific detail, number, or story carries it |
| TEACHES | understand a concept they did not before | the concept is named and explained from one example |

The brief locks one to three types. The edit stage checks each locked type against its test.
