# Format: log.md

Written by 04-implement, appended per task. This is the TDD evidence report, in the shape ECC's tdd-workflow skill asks for.

```markdown
# Implementation log: <slug>

Runner: <detected test runner and command>

## Task 1: <name>
- Red: <test file and name>; run: <command>; result: FAIL as expected
- Green: <files changed>; run: <command>; result: PASS
- Refactor: <what, or "none">
- Validate: `<command>`; result: PASS
- Unplanned changes: <none, or list with reasons>

## Task 2: ...

## Build breaks
| When | Error (first line) | Fix | Role file used |
|---|---|---|---|

## Coverage
<command and the number, or "not measured: <reason>">

## Open items
- <anything the reviewer must know>
```
