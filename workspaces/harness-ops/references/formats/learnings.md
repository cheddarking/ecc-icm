# Format: learnings.md (harness-ops)

Same shape as the engineering learnings, across every workspace.

```markdown
# Learnings: <slug>

Runs examined: <list, with workspace>
Edits examined: <n>

## Recurring edits
| Workspace | Stage | Kind of edit | Seen in runs | Example |
|---|---|---|---|---|

## Proposed source changes
### 1. <workspace>/<file>
- File: `$PLUGIN/workspaces/<workspace>/<path>`
- Change: <exact text to add, remove, or reword>
- Why: <which recurring edit it removes>
- Risk: <what could get worse>

## Not proposed
- <one-offs, with a sentence each>
```
