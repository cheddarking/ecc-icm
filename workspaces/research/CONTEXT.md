# Research Workspace

Questions answered with sources. Sequential, reviewable, repeatable.

## Task Routing

| Task Type | Go To | Description |
|---|---|---|
| Any new question, comparison, or "what does the literature say" | `stages/01-brief/CONTEXT.md` | Scope the question and define what counts as an answer |
| Collect evidence | `stages/02-gather/CONTEXT.md` | Sources with URLs, dates, and a one-line relevance note each |
| Make sense of the evidence | `stages/03-synthesize/CONTEXT.md` | Themes, disagreements, confidence per claim |
| Deliver | `stages/04-report/CONTEXT.md` | Cited report in the ECC deep-research shape |
